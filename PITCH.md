# Outreach Pitch: Listing Graphics at Scale

## The Offer Equation

```
Value = (Result × Probability of Success) / (Sacrifice × Time)
```

---

## RESULT (Numerator - Maximize)

### Surface Level
- Fast, consistent, high-quality graphics for every listing
- Scalable system that works across multiple agents
- Professional brand consistency

### Deeper Level (What She Actually Gets)
- **Reliability** - Never scrambling for graphics last minute
- **Reputation** - Looks competent and organized to agents and leadership
- **Freedom** - Mental bandwidth back, not managing one-off design requests
- **Control** - Dashboard visibility into what's being produced
- **Leverage** - One system serves many agents vs hiring/managing multiple designers

### Emotional Wins
- Less stress
- More trust from agents ("marketing always delivers")
- Looks like she built something smart

---

## PROBABILITY OF SUCCESS (Numerator - Maximize)

### Proof Points
- **Greg's testimonial**: "Closed a deal because of the graphics" (direct attribution)
- **Track record**: 18 graphics delivered across 2 packages (8-pack completed, 16-pack active)
- **Consistency**: Months of reliable delivery (Apr 2026 - present)
- **System exists**: Working platform demo at localhost:3001

### Future Proof (Roadmap Credibility)
- Instagram API integration (code already started)
- Analytics/tracking capability
- Content types beyond listings (homebuyer tips, market updates, etc.)
- Client portal for agent self-service

### Risk Reducers
- Already working with an agent she knows
- No learning curve - system handles complexity
- Can start small and scale

## SACRIFICE (Denominator - Minimize)

### Actual Cost
- Money (TBD - need to price)

- Compare to: hiring a designer ($50-80k/yr + management overhead)

- Compare to: DIY Canva (inconsistent, time sink, looks amateur)

### What It's NOT
- Not a time investment (you handle everything)
- Not a management burden (portal is self-service)
- Not a quality gamble (proven with Greg)

## TIME (Denominator - Minimize)

### Implementation Time
- System already built
- Onboarding: Send brand assets, get first graphic same day
- No training required for agents (portal is simple)

### Ongoing Time
- Agent submits listing → graphics delivered
- Director's involvement: Near zero after setup

- Agents continue with inconsistent/no graphics
- Competitors' agents look more professional

- Other brokerages adopt systematized marketing first

### Status Quo is Not Safe
- "Doing nothing" still has a cost

- Agents notice when marketing doesn't support them
